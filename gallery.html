计算原理与公式

假设使用模式不变，总输入（非缓存输入 + 缓存输入）与总输出（含推理）的比例沿用 Pro 20x 样本。中转站切号后，部分原本可命中缓存的输入可能变成非缓存输入，总输入和输出不变。因此，只需根据中转缓存率重新拆分输入，就能结合单价、计费倍率和充值倍率算出相同用量的实际成本。再计算 $200 能购买多少份这样的用量，并按 Pro 20x 样本的标准 API 价格折算，即得到可比较的 API 等价额度。

总输入、总输出取 Pro 20x 样本，单位为百万 token；缓存率取中转设置，充值倍率为每 ¥1 可充值的美元额度。

中转样本标准价费用 = 总输入 × [(1 − 缓存率) × $10 + 缓存率 × $1] + 总输出 × $50 中转样本实付（元）= 中转样本标准价费用 × 计费倍率 ÷ 充值倍率 可购买的样本份数 = ($200 × 6.7223) ÷ 中转样本实付（元） API 等价额度 = 可购买的样本份数 × Pro 20x 原始样本标准价费用
